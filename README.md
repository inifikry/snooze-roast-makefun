# Snooze Button Roast

One line roasting an alarm clock that rings at 6 AM on a Saturday.

## The line

> My alarm clock rings at 6 AM on Saturday like a rooster that got fired from the farm and took it personally.

## How it works

`main.py` writes the roast to `/output/entry.txt`. That is all it does:
no arguments, no network, no dependencies beyond the Python standard
library.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
